# 找自己

这是一个从「价值观 → 才能 → 理想与愿望 → 可能方向」开始探索的独立静态网站。

## 使用

直接打开 `index.html` 即可使用。所有回答和结果只保存在当前浏览器的 localStorage 中，不会发送给 AI 或其他服务器。

## 发布到网上

这个版本不需要后端，可以直接发布到 GitHub Pages、Netlify 或 Cloudflare Pages。发布时只需要上传 `index.html`、`styles.css` 和 `app.js`。

职业收入默认显示中国市场的宽范围和中位数参考，也可以切换到美国；页面提供视频和从业案例搜索入口，仍需要结合地区、经验和具体岗位继续核实。
